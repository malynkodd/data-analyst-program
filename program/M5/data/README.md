# Сквозной датасет модуля M5 (Python)

## Статус этого файла

Полная декларация датасета — `program/M5/step-00.md` (категория датасета,
что именно в нём сломано и зачем, разбивка умений по шагам). Этот файл —
описание папки `data/` для человека, который её открыл, а не второй
источник истины.

Домен — fintech: платёжный сервис, выплаты партнёрам (решение 21, п. 2).
Данные синтетические, генератор детерминирован, `SEED = 20260817`.

**Сами данные в репозиторий не коммитятся** (решение 29
`design/decisions.md`): папка `raw/` перечислена в корневом `.gitignore`.
В git лежат генератор, скрипт эталонов и четыре эталонных CSV.

## Порядок загрузки

Правило — решение 20 `design/decisions.md`: файл данных появляется в том
шаге, где он нужен впервые, и `step-00.md` этого не дублирует. Здесь —
план; команды пишутся в самих шагах.

| Шаг | Что появляется | Файлы |
|---|---|---|
| `step-01.md` | окружение и весь `raw/` сразу: генератор запускается один раз на модуль, сверяется контрольная точка | `raw/` целиком |
| `step-03.md` | ничего нового: читается одна выгрузка из четырёх | `raw/payouts_2026_q1.csv` |
| `step-04.md` | ничего нового: к первой выгрузке добавляются остальные три файла | `raw/payouts_2026_q2.csv`, `raw/partners.xlsx`, `raw/fees_api.json` |
| `step-05.md` | ничего нового: join'ы поверх загруженного | — |
| `step-06.md` | ничего нового: функция метрики и тесты поверх собранного DataFrame | — |
| `step-07.md` | ничего нового: сборка расчёта в `run.py` | — |
| `step-08.md` | ничего нового: график по `ref_month_gross.csv` | — |
| `step-09.md` | большая выгрузка: генератор запускается один раз | `raw/payouts_big.csv` |

Накопительных состояний, как в M3, здесь нет: датасет неизменен, меняется
код учащегося. Таблица оставлена в том же формате, что у остальных
модулей, чтобы правило решения 20 не приходилось искать заново.

## Как воспроизвести с нуля

```
$ python -m pip install pandas openpyxl matplotlib pytest
$ python program\M5\data\generate_m5.py
$ python program\M5\data\reference_m5.py
```

Первая команда — предусловие модуля (`step-00.md`). Вторая пишет `raw/` и
печатает контрольную точку. Третья пересчитывает четыре `ref_*.csv` и
печатает все числа, на которые ссылаются шаги.
