# M9.05. Разбирает 10 ловушек про корреляцию, причинность и агрегацию

Умение: F2
Модуль: M9
Требуется до этого: `step-04.md` этого модуля
Новые файлы, объявляемые этим шагом: `program\M9\work\traps_d_answers.md`
Время: 4–5 ч

## 1.1. Цель и связь с умением

Завершает обучающую часть F2 (40 ловушек): последняя группа — про то,
что связь между числами (корреляция, схожий тренд, агрегат по группам)
не равна утверждению о причине.

## 1.2. Теория своими словами

**Корреляция не различает четыре возможности сама по себе.** У любой
связи между X и Y объяснений минимум четыре: X вызывает Y, Y
вызывает X, третья переменная вызывает оба, либо связь ложная —
совпадение, общий тренд, особенность отбора выборки. Само по себе число
не скажет, какое из четырёх верно. Выбрать позволяют только
формулировка вопроса и знание механизма.

## 1.3. Разобранный пример — все 10 ловушек группы

Прогон `traps_d.py` на машине автора 2026-08-20.

**D31. Классический конфаундер.**
```
Вопрос: Продажи мороженого коррелируют с утоплениями (r=0.44).
  Мороженое опасно?
Неверный ответ: да, корреляция говорит о причинной связи
Правильный ответ: нет — обе переменные вызваны температурой (жара →
  больше мороженого и больше купания)
```

**D32. Обратная причинность.**
```
Вопрос: Компании с высокими расходами на охрану труда имеют меньше
  травм. Увеличение бюджета снизит травматизм?
Неверный ответ: да, больше бюджета — меньше травм
Правильный ответ: возможна обратная стрелка — изначально безопасные
  компании могут позволить себе больше инвестировать
```

**D33. Парадокс Берксона (коллайдер).**
```
Вопрос: Среди отобранных в программу (по сумме талант+харизма выше
  порога) талант и харизма отрицательно коррелируют (r=-0.62). Одно
  мешает другому?
Датасет: до отбора r=0.02 (около нуля), среди 489 отобранных r=-0.62
Неверный ответ: да, высокий талант компенсируется низкой харизмой
Правильный ответ: нет прямой связи — отрицательная корреляция создана
  самим правилом отбора по сумме, а не качествами
```

**D34. Экологическая ошибка.**
```
Вопрос: В регионах с высоким средним доходом выше явка. Богатые
  избиратели голосуют чаще?
Неверный ответ: да, богатые голосуют активнее
Правильный ответ: связь на уровне регионов не обязана сохраняться на
  уровне людей — агрегированные данные не заменяют индивидуальные
```

**D35. Ложная корреляция через общий тренд.**
```
Вопрос: Пользователи приложения и продажи мороженого коррелируют за
  30 месяцев (r=0.97). Есть связь?
Неверный ответ: да, связь заметная — стоит изучить механизм
Правильный ответ: ложная корреляция за счёт общего временного тренда —
  любые два растущих ряда дадут высокий r без содержательной связи;
  проверка — включить время как контроль или смотреть на приросты
```

**D36. Простое среднее вместо взвешенного.**
```
Вопрос: Оценка A — 4.8 (n=1000), B — 3.2 (n=50). Средняя платформы —
  4.00?
Датасет: простое среднее 4.00, взвешенное 4.72
Неверный ответ: да, 4.00 — среднее двух чисел
Правильный ответ: нет — нужно взвесить по числу отзывов (4.72); простое
  среднее завышает вес B в 10.5 раза относительно его доли отзывов
```

**D37. Смена знаменателя между периодами.**
```
Вопрос: Доля конверсии выросла с 4.0% до 5.2%. Продукт стал лучше
  конвертировать?
Датасет: месяц 1: 400/10000; месяц 2: 420/8000 (числитель почти не
  изменился)
Неверный ответ: да, доля выросла на 1.2 п.п.
Правильный ответ: рост вызван сокращением базы (например, изменилось
  определение «активного пользователя»), не улучшением конверсии
```

**D38. Выброс определяет среднее малой группы.**
```
Вопрос: Средний чек группы из 5 клиентов — 999 грн. Типичный чек этой
  группы?
Датасет: чеки [120, 135, 110, 128, 4500]
Неверный ответ: да, типичный чек — 999 грн
Правильный ответ: нет — один чек на 4500 сдвигает среднее с 123 (без
  него) до 999; медиана (128) устойчивее и лучше описывает типичного клиента
```

**D39. Направление причинности не установлено.**
```
Вопрос: Компании с высокой удовлетворённостью сотрудников показывают
  выше прибыль. Инвестировать в HR-программы ради прибыли?
Неверный ответ: да, счастье сотрудников — причина прибыли
Правильный ответ: возможна обратная стрелка — прибыльные компании
  могут больше платить; различить направления можно только экспериментом
```

**D40. Пропуски не случайны (MNAR).**
```
Вопрос: Средняя оценка по 474 ответившим из 500 — 7.21 из 10.
  Пропуски можно игнорировать как шум?
Датасет: истинное среднее по всем 500 — 6.99, по ответившим — 7.21
Неверный ответ: да, недостающие ответы не смещают среднее
Правильный ответ: нет — недовольные реже отвечают на опрос
  (Missing Not At Random), среднее по ответившим завышено на 0.21
```

## 1.6. Типичные ошибки

**Ошибка:** D35 в первой версии скрипта задавала второй ряд убывающим
(`500 - 1.5*t`), пока первый ряд возрастал — итоговая корреляция
получилась слабой и отрицательной (r=-0.24), что не подходило под
классический пример «два растущих ряда создают иллюзию связи».
**Почему выглядит правильно:** отрицательная корреляция — тоже связь, и
формально ловушка «ложная корреляция» остаётся ложной.
**Почему неправильно:** классический вариант ловушки (мороженое и
непрофильный показатель) в обиходе — про **положительную**, визуально
убедительную связь между двумя растущими рядами; слабый отрицательный
r не создаёт того интуитивного «ага, тут явно что-то есть», ради
которого ловушка задумана — сила примера в его убедительности, а
r=-0.24 не убеждает никого ошибиться.
**Как правильно:** оба ряда заданы возрастающими с близким наклоном и
низким шумом — r=0.97, убедительный пример того самого интуитивного
ложного вывода, который ловушка должна спровоцировать.

**Ошибка:** D36 в первой версии объясняла завышение веса B словами «в
20 раз», не пересчитав отношение фактически.
**Почему выглядит правильно:** 1000 против 50 на глаз дают внушительное
круглое число, и 20 выглядит правдоподобно.
**Почему неправильно:** фактическое отношение веса B в простом среднем
(50%) к его весу по факту (50 из 1050 отзывов, 4.8%) — 10.5, не 20;
округление «на глаз» без пересчёта дало неверное число в тексте,
который сам же учит не полагаться на числа без проверки.
**Как правильно:** каждое число в объяснении ловушки пересчитывается
явно, тем же правилом, что применяется к самим ловушкам (решение 30
`design/decisions.md`: число — вместе с определением, которое его
породило).

## 1.8. Вопрос уровня собеседования

**Вопрос:** «Вы нашли корреляцию r=0.6 между двумя метриками продукта.
Назовите все правдоподобные объяснения, прежде чем делать вывод о
причинности.»

**Эталон (ответ покрывает ≥3 из 4 пунктов):**
1. X вызывает Y напрямую.
2. Y вызывает X (обратная причинность).
3. Третья переменная вызывает обе (конфаундер) — включая частный
   случай, где переменная — само время (общий тренд).
4. Связь артефакт способа отбора наблюдений (парадокс Берксона) или
   агрегации данных (экологическая ошибка) — сама выборка создала
   связь, которой нет в исходных данных.
