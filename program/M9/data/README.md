# Датасеты модуля M9 (40 ловушек статистики)

## Статус этого файла

Полная декларация — `program/M9/step-00.md`, раздел «Датасет — 40
независимых микро-датасетов». Этот файл — описание папки `data/`.

Данные синтетические, каждый скрипт детерминирован (`SEED` фиксирован
до первого обращения к `random`). Общей контрольной точки одной
таблицей нет — вместо неё `reference_answers.md` со всеми 40 числами.

## Файлы

| Файл | Роль | В git? |
|---|---|---|
| `traps_a.py` | Ловушки 1–10 (выборка, случайность, смещение) — `step-02.md`. Печатает вопрос/датасет/оба ответа каждой. | да |
| `traps_b.py` | Ловушки 11–20 (значимость, множественные сравнения) — `step-03.md`. | да |
| `traps_c.py` | Ловушки 21–30 (устройство A/B-экспериментов) — `step-04.md`. | да |
| `traps_d.py` | Ловушки 31–40 (корреляция, причинность, агрегация) — `step-05.md`. | да |
| `reference_answers.md` | Все 40 ключевых чисел, сверяемых при чтении шага. | да |
| `exam.py` | Закрытый набор F2 — 10 вопросов, не совпадающих с 40 ловушками, для `step-06.md`. Не читать до собственного ответа. | да |
| `ab_report_sample.md` | Отчёт A/B-теста с тремя встроенными дефектами (умение F3) для `step-06.md`. | да |

Датасеты каждой ловушки не пишутся на диск отдельными файлами —
генерируются и используются внутри своего скрипта немедленно (15–2000
строк/точек, не требуют хранения). Ничего не коммитится и не
попадает в `.gitignore`: сохранять нечего.

## Как воспроизвести

```
$ .venv\Scripts\python.exe program\M9\data\traps_a.py
$ .venv\Scripts\python.exe program\M9\data\traps_b.py
$ .venv\Scripts\python.exe program\M9\data\traps_c.py
$ .venv\Scripts\python.exe program\M9\data\traps_d.py
$ .venv\Scripts\python.exe program\M9\data\exam.py
```

Каждая команда печатает десять ловушек целиком — вопрос, датасет,
неверный и правильный ответы, ключевое число. `exam.py` — закрытый
набор для `step-06.md`: не запускать до собственного ответа.
