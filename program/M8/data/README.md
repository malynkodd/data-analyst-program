# Сквозной датасет модуля M8 (Бизнес- и продуктовые метрики)

## Статус этого файла

Полная декларация — `program/M8/step-00.md`. Этот файл — описание папки
`data/` для человека, который её открыл, а не второй источник истины.

Домен — fintech (решение 21, п. 2): сервис микрокредитов, привлечение
клиентов через маркетинговые каналы. Данные синтетические, генератор
детерминирован, `SEED = 20260822`.

**Сами данные в репозиторий не коммитятся** (решение 29): папка `raw/`
в корневом `.gitignore`.

## Файлы

| Файл | Роль | В git? |
|---|---|---|
| `generate_m8.py` | Генератор. Пишет `raw/` — три CSV. Детерминирован: печатает число строк, sha256 и инварианты (лиды/конверсии/зрелость когорт). | да |
| `reference_m8.py` | Считает эталоны заново, независимо от внутренних списков генератора, пишет два `ref_*.csv`. В докстроке — восемь правил канона модуля (по одному на метрику, с базой и окном). | да |
| `reference_m8_product.py` | Эталоны шагов 04–06 (умения F6, F7, F8): продуктовые метрики, RFM-сегменты, юнит-экономика, сезонность и MAPE. Считается стандартной библиотекой, без `pandas`. В докстроке — определения базы, окна, метода квантиля и правила сравнения с границей. | да |
| `ref_product_metrics.csv` | Эталон шага 04: ARPU, ARPPU, конверсия, DAU/WAU/MAU, sticky, помесячная выручка, MoM, повторная выручка. 16 строк. | да |
| `ref_rfm_segments.csv` | Эталон шага 05: 21 непустой RFM-сегмент — клиенты, выручка, доля. 21 строка. | да |
| `ref_unit_economics.csv` | Эталон шага 05: CAC, ARPPU, вклад, окупаемость. 7 строк. | да |
| `ref_forecast.csv` | Эталон шага 06: семь коэффициентов дня недели, база, два MAPE и run-rate. 13 строк. | да |
| `reference_answers.md` | Контрольная точка и все восемь метрик с определением каждой. | да |
| `ref_channel_metrics.csv` | Эталон шага 01: CPL и CPA по трём платным каналам. 3 строки. | да |
| `ref_business_metrics.csv` | Эталон шагов 02–03: CAC, LTV_D30, ROAS, ROMI, ROI, Retention_D30, Churn_D30. 7 строк. | да |
| `raw/leads.csv` | Все лиды: `lead_id, channel, signup_date, user_id, conversion_date`. Пустые `user_id`/`conversion_date` — не конвертировался. 2988 строк. | **нет** — создаётся генератором |
| `raw/revenue.csv` | Транзакции дохода конвертированных клиентов: `user_id, txn_date, amount`. 5389 строк. | **нет** |
| `raw/channel_spend.csv` | Расход по каналам помесячно: `channel, month, spend_uah`. Только три платных канала — `organic` не логирует расход. 12 строк. | **нет** |

Сверка своего CSV с эталонным — `compare_csv.py` из `program/M3/data/`.
