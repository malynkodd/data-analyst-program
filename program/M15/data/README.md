# Данные модуля M15 (Tableau, конверсионный модуль)

## Статус этого файла

Полная декларация — `program/M15/step-00.md`. У модуля нет собственного
датасета: предмет переноса — уже собранная и сверенная модель
`program/M4/data/csv/` (пять таблиц) и эталоны `program/M4/data/ref_*.csv`.

**Модуль написан без доступа к Tableau Public** (структурное
ограничение, `step-00.md`, «Отступление от конвенции модуля») — все
пути в меню и синтаксис вычисляемых полей проверены официальной
документацией (fetch 2026-08-21), не прогоном. Первый реальный прогон —
`DEFERRED.md`, раздел «Проверка Tableau Public».
