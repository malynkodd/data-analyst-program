# Данные проекта P3 («Дашборд, который заменяет еженедельную рассылку»)

## Статус этого файла

Полная декларация — `program/P3/step-00.md`. Данные — **реальные
публичные**, зафиксированные снапшотом (часть 5 blueprint,
«Реальные публичные данные — P3, P4, P6»), не синтетика.

**Снапшот коммитится в репозиторий, а не генерируется заново.** Оба
источника (Prozorro API, API НБУ) — живые потоки без версионирования:
повторный запрос тех же параметров вернёт **другие** данные (новые
тендеры, обновлённые статусы, новые даты в курсовом ряду). Правило
решения 29 («датасет воспроизводится генератором») здесь неприменимо
буквально — вместо него действует общее правило части 5 blueprint:
«автор фиксирует снапшот — файл, дата выгрузки, sha256; acceptance
criteria считаются по снапшоту». Оба скрипта в этой папке — не
генераторы для CI, а **инструмент выгрузки**, которым пользовался
автор и которым позже воспользуется учащийся для собственной, отдельно
датированной, повторной выгрузки (критерий 11 части 5).

**`robots.txt` не блокирует ни один из двух источников** (проверено
2026-08-21): `bank.gov.ua/robots.txt` — `Disallow:` пустой (разрешено
всё); у `public.api.openprocurement.org` `robots.txt` вовсе не
существует (404). Правило раздела 4 скилла curriculum-design («робот
данные не качает») написано под `data.gov.ua`, который явно блокирует
AI-краулеров, — здесь это ограничение не действует, и снапшот выгружен
этим заходом напрямую.

## Закрыто турникетом (решения 51 и 53)

| Файл | Что внутри |
|---|---|
| `answers.md.enc` | Разбор эталона: ответы, ранги, выбранные трактовки, разбор дефектов. Вынесен из `reference_answers.md`. |

Открывается только после сохранённой попытки, проход пишется в
`research/attempts.md`:

```
> python tools\vault.py open <путь без .enc> --attempt <файл вашей попытки>
```

Эталонной таблице нужен файл на диске, а не вывод в консоль — её
читает `compare_csv.py`, а не человек. Для этого у `open` есть `--to`:

```
> python tools\vault.py open <путь без .enc> --attempt <файл> --to <папка>\unlocked\<имя>
```

Каталог `unlocked/` — в `.gitignore`. Раздел «Проверка строк» ниже
сверяет закрытые таблицы через тот же турникет, поэтому закрытие
файла не отключает проверку (`tools/check_consistency.py`).
