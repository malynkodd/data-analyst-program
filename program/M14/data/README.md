## Статус этого файла

Полная декларация — `program/M14/step-00.md`. У модуля нет собственного
генератора и нет синтетического датасета: J3/J4 — фактология
фиксированного объёма (пять реальных компаний, пять параметров схемы
ФОП группы 3, пять пунктов «чего не делать»), не расчёт на данных.
Источники — `research/access.md` (разделы 2–4) и `research/market.md`
(junior-сегмент украинской выборки).
