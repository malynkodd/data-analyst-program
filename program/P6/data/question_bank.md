# Банк вопросов для защиты (критерий 13)

Восемь вопросов про проект P6. На защите учащийся отвечает на **5 из
8**, выбранных не им самим — до защиты неизвестно, какие именно.
Каждый эталон — ответ обязан содержать конкретное число из
`program/P6/data/reference_answers.md`, не общую фразу.

1. **Какой регион показал наибольший средний рост розничной торговли,
   и почему это не то же самое, что «рост спроса на нашу категорию»?**
   Эталон: Харьковская область, 130.6 (среднее YoY, 2021-M01…2026-M06);
   индикатор — вся розница региона, разреза по категории «обувь» в
   этом источнике нет.
2. **Три региона отсутствуют в снапшоте розницы полностью. Какие, и
   что это значит для отчёта?**
   Эталон: АРК, Севастополь, Луганская область — 0 строк за весь
   период; вывод по этим регионам сделать нельзя вообще, не «около
   нуля».
3. **Импорт обуви в файле выглядит так, будто растёт весь год и резко
   падает в январе. Это реальный спад спроса в январе?**
   Эталон: нет — данные Держстата идут накопительным итогом с начала
   года; «падение» в январе — сброс накопительного счётчика, не спад;
   наивная трактовка ноября 2024 как «месячного» числа даёт 35 532 703
   пары — в 30+ раз больше настоящего месячного значения.
4. **Средняя цена импортной пары выросла почти вдвое с 2020 по 2022 год
   (6.34$ → 11.11$). Это доказывает, что скоро розничные цены тоже
   вырастут на столько же?**
   Эталон: нет причинного доказательства — себестоимость импорта не
   равна розничной цене (наценка, локальные издержки, конкуренция
   неизвестны); совпадает по времени с ростом курса USD/UAH, но
   различить вклад курса и общей инфляции этим датасетом нельзя.
5. **Заказчик просит количественный ответ на «+15% цены — что будет со
   спросом?». Что вы ему скажете?**
   Эталон: количественно ответить нельзя — ни один из трёх источников
   не содержит наблюдаемой пары «цена товара → объём продаж этого же
   товара»; нужны внутренние данные ритейлера (кассовые чеки/1С),
   которых нет в открытой государственной статистике.
6. **Какой из трёх найденных дефектов был самым дорогим — то есть
   больше всего исказил бы вывод, если бы его не заметили?**
   Эталон: своя оценка с обоснованием — кумулятивный сброс импорта
   (30+ кратное искажение при наивном прочтении) — сильный кандидат,
   но приемлем любой из трёх с конкретной цифрой ошибки.
7. **Executive summary называет одну рекомендацию. Какая, и с каким
   числом она подкреплена?**
   Эталон: своя рекомендация из отчёта, число — из собственного
   summary, не из этого банка.
8. **Одна из двух причин, по которым вывод может быть неверным, — про
   выборку, определение или период. Что изменится в выводе, если эта
   причина подтвердится?**
   Эталон: своя причина, конкретное следствие для вывода — не общая
   фраза «вывод станет менее надёжным».
