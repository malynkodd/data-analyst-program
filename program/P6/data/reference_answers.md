## Определения (решение 30)

- **idx_yoy_pct** — индекс оборота розничной торговли за месяц к тому же
  месяцу предыдущего года, без сезонной корректировки (Держстат,
  `IDX_TRNVR_RTL_TRADE_VOL`/`UNADJ_CORR_MON_PREV_Y`). 100 = без
  изменений год к году, >100 = рост. **Не разбит по товарной
  категории** — это вся розница региона целиком, найдено при выборе
  потока: разреза «регион × категория одновременно» в этом источнике
  нет вообще.
- **Помесячный импорт обуви** — `footwear_imports.csv` из Держстата
  идёт **накопительным итогом с начала года** (найдено прогоном, не в
  описании blueprint): у каждого из 10 лет (2015–2024) по 11 значений
  (M01…M11, декабрь отсутствует структурно во все годы), каждое
  следующее больше предыдущего, и в начале следующего года — резкий
  сброс. Настоящее месячное число — разница с предыдущим месяцем того
  же года; `reference_p6.py` считает это явно, не берёт значение «как
  есть».
- **Средняя цена импортной пары** — накопленная за год стоимость
  (тыс.$) × 1000 / накопленное за год количество (пар) — себестоимость
  импорта в среднем за год, **не розничная цена** и не показатель
  эластичности спроса.

`retail_turnover_by_region.csv` не содержит **ни одной** строки для
Автономной Республики Крым, Севастополя и Луганской области за весь

проектом (вероятно — оккупация и разрушенная статистическая
инфраструктура), но сам факт отсутствия — часть отчёта, не молчание.

## Критерии 2, 3, 8 — день-3 вопрос (+15% цены): что нельзя посчитать

Ни один из трёх источников не содержит наблюдаемой пары «цена
изменилась → спрос изменился» для одного и того же товара:

- `retail_turnover_by_region.csv` — динамика спроса по региону, но без
  цены и без категории.
- `footwear_imports.csv` — себестоимость импорта по категории (после
  снятия кумулятивного сброса), но не розничная цена и не по региону.
- `usd_uah.csv` — курсовой контекст (себестоимость в гривне), тоже не
  цена и не спрос.

**Что нужно было бы собрать** (критерий 3): панель «розничная цена по
SKU/категории × объём продаж по SKU/категории × регион × время» —
такого источника в открытых государственных данных Украины нет; это
внутренние данные ритейлера (кассовые чеки/1С), не публичная
статистика.

Средняя цена импортной пары обуви по годам (себестоимость, для
контекста, не ответ на вопрос):

```
2015: 6.50$   2019: 5.92$   2022: 11.11$
2016: 6.17$   2020: 6.34$   2023: 12.13$
2017: 4.97$   2021: 9.79$   2024: 11.24$
2018: 6.31$
```

Рост с ~$6 (2015–2020) до ~$11–12 (2022–2024) совпадает по времени и с
курсовым давлением (USD/UAH среднее 2024 — 40.16), и с общей
инфляцией — обе причины правдоподобны одновременно, различить их этим
датасетом нельзя (критерий 15 — не делать причинного утверждения без
оговорки).
