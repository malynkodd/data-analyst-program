# M1.00. Декларация модуля (умения, датасет, шаги)

Не шаг для учащегося — служебный файл, требуемый разделом 1.3 скилла
curriculum-design: датасет и состав модуля объявляются один раз, до
первого содержательного шага. Написан задним числом при ревью пилота
(изначально M1 был написан без отдельного `step-00.md`, декларация была
размазана по `data/README.md`); правило на будущее — шаг 0 пишется
первым, а не восстанавливается после того, как остальные шаги готовы.

## Умения модуля и их шаги

Модуль M1 закрывает A5 и H2 (часть 2.2 blueprint), 8–10 ч.

| Умение | Часть умения | Шаг | Часы |
|---|---|---|---|
| A5 | Первая половина: 3 уточняющих вопроса по неоднозначному бизнес-вопросу | `step-01.md` | 2.5–3 |
| A5 | Вторая половина: письменная фиксация определения до расчёта, демонстрация чувствительности к определению | `step-02.md` | 3.5–4.5 |
| H2 | Первое, вводное закрытие (называет 2 причины, вывод может быть неверным); полностью — в M12 | `step-03.md` | 2–2.5 |

Сумма: 8.0–10.0 ч при вилке части 6.1 blueprint 8–10.

**Оценка сведена к вилке, не измерена** (решение 24
`design/decisions.md`). Совпадение по обеим границам — признак подгонки
суммы под заранее известное число, а не подтверждение оценок. Часы не
переоцениваются задним числом; разрешит вопрос `research/self.md`,
на 2026-07-30 пустой. Строка M1 в части 6.1 помечена «**Требуется**
калибровка — нет ни одного ориентира ни в [М], ни в [К]», то есть
исходная вилка здесь и сама ни на чём не стоит.

## Датасет модуля

**Категория:** сквозной модуль вне проектной привязки — синтетика по
умолчанию (третья категория раздела 1.3 curriculum-design, добавлена
2026-07-30 по итогам ревью этого же пилота).

**Файлы:** `program/M1/data/` — полное описание в `data/README.md`.
Сводка:

| Файл | Роль |
|---|---|
| `generate_clients.py` | Генератор `clients.csv`, детерминирован (`SEED=20260701`, `REFERENCE_DATE=2026-07-01`) |
| `clients.csv` | 240 строк, эталон для всех критериев готовности модуля |
| `count_active.py` | Подсчёт по параметризованному определению (M1.2) |
| `peek_clients.py` | Фильтрация/просмотр строк (M1.1) — кросс-платформенная замена `grep`+`awk` (решение 13) |
| `check_order.py` | Сравнение mtime двух файлов — резервный инструмент, в M1.2 не используется как критерий (см. решение 14: критерий теперь через `git log`) |
| `reference_answers.md` | Предвычисленные контрольные числа |

Датасет не меняется между `step-01.md`, `step-02.md`, `step-03.md`.

## Зависимости модуля

M0 — жёсткая зависимость (часть 3.2 blueprint, добавлено при написании
этого пилота): `step-01.md` использует терминал/скрипты (I2), `step-02.md`
использует `git commit` (решение 14, I1 частично). Без прохождения M0
шаги M1 не выполнимы буквально, не только желательны.
