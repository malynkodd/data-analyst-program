# Сквозной датасет модуля M6 (Данные, которые ломаются)

## Статус этого файла

Полная декларация датасета — `program/M6/step-00.md` (категория датасета,
что именно в нём сломано и зачем, разбивка умений по шагам). Этот файл —
описание папки `data/` для человека, который её открыл, а не второй
источник истины.

Домен — fintech (решение 21, п. 2): сверка внутреннего леджера платёжного
сервиса с расчётной выпиской эквайера за один квартал. Данные
синтетические, генератор детерминирован, `SEED = 20260821`.

**Сами данные в репозиторий не коммитятся** (решение 29
`design/decisions.md`): папка `raw/` перечислена в корневом `.gitignore`.
В git лежат генератор, скрипт эталонов и четыре эталонных CSV.

| Файл | Роль | В git? |
|---|---|---|
| `generate_m6.py` | Генератор. Пишет `raw/` — два файла. Детерминирован: печатает число строк, sha256 каждого файла и восемь инвариантов (дубли ретраев, окно отставания, висячие расчёты, нарушения статуса, выбросы). | да |
| `reference_m6.py` | Считает эталоны заново, независимо от внутренних списков генератора (правило двойного авторства, скилл, раздел 1.3), и пишет четыре `ref_*.csv`. В докстроке — шесть правил канона модуля. | да |
| `reference_answers.md` | Контрольная точка датасета (sha256 + строки) и эталонные числа по каждому умению. | да |
| `ref_match_report.csv` | Эталон шага 01: паспорт первого прохода сверки — сколько `completed`-операций, у скольких есть расчёт, сколько расчётов без основания. 4 строки. | да |

| `ref_orphan_settlements.csv` | Эталон шага 01: расчёты, ссылающиеся на несуществующий `ledger_txn_id`. 15 строк. | да |
| `ref_status_violations.csv` | Эталон шага 04: нарушения правил статуса (`failed`, но расчёт пришёл; `reversed` без компенсации в срок). 29 строк. | да |
| `reference_m6_stats.py` | Эталоны шага 05 (умение F4): считает описание распределения и сравнение четырёх правил порога стандартной библиотекой — без `pandas` и без `statistics.quantiles`, чтобы эталон и решение учащегося не были одним вызовом (двойное авторство). | `ref_distribution.csv` | Эталон шага 05: описание распределения суммы `completed`-операций двенадцатью числами. 12 строк. | да |
| `ref_thresholds.csv` | Эталон шага 05: четыре правила отсечения выбросов на одной колонке — найдено, совпало, ложных, пропущено. 4 строки. | да |
| `ref_outliers.csv` | Эталон шага 03: статистические выбросы суммы относительно медианы своего счёта. 10 строк. | да |
| `raw/ledger.csv` | Внутренний леджер: `txn_id, account_id, amount, currency, ts, status`. UTF-8, запятая, десятичная точка, ISO-время. 2324 строки. | **нет** — создаётся генератором |

## Как воспроизвести с нуля

```
$ .venv\Scripts\python.exe program\M6\data\generate_m6.py
$ .venv\Scripts\python.exe program\M6\data\reference_m6.py
```

Первая команда пишет `raw/` и печатает контрольную точку. Вторая
пересчитывает четыре `ref_*.csv` и печатает все числа, на которые
ссылаются шаги. Пакетов сверх тех, что стоят с шага 01 модуля M5
(`pandas`, `openpyxl`, `matplotlib`, `pytest`), не требуется — оба
скрипта используют только стандартную библиотеку.
