## Шаг 02 — сверка `completed`-операций объяснена целиком (B2)

Эталон — `ref_unmatched_report.csv` (51 строка) и
`ref_orphan_settlements.csv` (15 строк).

| Показатель | Число | Определение |
|---|---|---|
| операций `completed` в леджере | 2047 | статус `completed`, без фильтра по дате |
| из них без расчёта (`ledger_txn_id` не встречается ни в одной положительной записи `settlement.csv`) | 51 | база — только `completed`; сопоставление по точному `ledger_txn_id` |
| — в пределах окна отставания (дата операции позже 28.03.2026) | 28 | последние 3 дня периода (`PERIOD_END − 3`), причина проверяется первой |
| — дубль ретрая (тот же счёт, та же сумма, разница меток времени ≤60 с с другой такой же операцией, которая расчёт получила) | 23 | причина проверяется второй, только для операций вне окна отставания |
| — необъяснено | **0** | это и есть критерий шага: список из двух причин исчерпывает все 51 |
| расчётов, ссылающихся на `ledger_txn_id`, которого нет в леджере вовсе | 15 | сравнение с полным множеством `txn_id` леджера, оба статуса — не важны |

**Почему дубль-ретраев в отчёте 23, а не 25.** Генератор внёс ровно 25 пар
дублей, но у двух пар вторая операция по времени попала в последние три
дня периода. Правило шага «сначала окно отставания, потом дубль» относит
эти две операции к первой причине — обе формулировки верны для них
одновременно, порядок проверки в каноне (правило 2 раньше правила 4)
определяет, в какую строку они попадут. 26 (окно) + 25 (дубль) = 51 по
генератору; 28 + 23 = 51 по правилу шага — то же число, другая раскладка.

## Шаг 03 — статистические выбросы (B2)

Эталон — `ref_outliers.csv` (10 строк). Порог — сумма операции более чем
в 5 раз выше медианы по этому же счёту (правило 6 канона). Медиана, а не
среднее: единичная операция в 12 раз крупнее обычной сдвигает среднее
счёта заметно, а медиану — нет, потому что она использует только
положение, не величину выброса.

Первые две строки: `T000448` (счёт `ACC-0039`) — 45 850.00 грн при
медиане счёта 3 727.50, **12.3×**; `T000556` (счёт `ACC-0024`) —
40 250.00 грн при медиане 3 570.00, **11.3×**. Все 10 строк —
`ref_outliers.csv`.

## Что измерено прогоном, а не выведено из кода генератора

`reference_m6.py` не читает внутренние списки `generate_m6.py` — числа
выше посчитаны второй, независимой реализацией по тем же двум CSV,
которые видит учащийся. Совпадение с инвариантами, которые печатает сам
генератор (26/25 против 28/23, 15, 8, 21, 10), проверено построчно при
написании этого файла: единственное решённое несовпадение — раскладка
26/25 против 28/23, объяснённая выше, все остальные пять чисел совпали
без расхождений с первого прогона.
