# M0.00. Декларация модуля (умения, датасет, шаги)

Не шаг для учащегося — служебный файл, требуемый разделом 1.3 скилла
curriculum-design: датасет и состав модуля объявляются один раз, до
первого содержательного шага.

## Умения модуля и их шаги

Модуль M0 закрывает I2 целиком и фрагмент I1 (`git init`/`add`/`commit`,
решение 14 `design/decisions.md` — остаток I1, branch/PR/merge, закрыт в
M10), 9–11 ч (часть 2.2 blueprint).

I2 в части 1 blueprint — 6 задач: «переходит в каталог, запускает готовый
скрипт, создаёт и правит текстовый файл в рабочей папке (сохраняет в
UTF-8, редактор — на усмотрение учащегося), смотрит первые 20 строк csv
без Excel, считает строки в файле, находит строку по подстроке (три
последних — через предоставленные скрипты, решение 13)». Проверка: 6
задач из 6 без подсказки.

| Умение | Часть умения | Задачи I2 | Шаг | Часы |
|---|---|---|---|---|
| I2 | Терминал: установка Python и Git, навигация, запуск скрипта, текстовый файл в UTF-8 | 1, 2, 3 | `step-01.md` | 3.5–4 |
| I2 | Терминал через скрипты: просмотр/счёт/поиск (решение 13) | 4, 5, 6 | `step-02.md` | 3–3.5 |
| I1 (фрагмент) | `git init`/`add`/`commit` и отмена изменений (`status`/`diff`/`restore`), файловые операции | — | `step-03.md` | 2.5–3.5 |

Сумма: 9.0–11.0 ч при вилке части 6.1 blueprint 9–11.

Вилка росла дважды. Контентный аудит 2026-08-28 (решение 54): 7–9 → 8–10,
`step-03.md` получил отмену изменений (`git status`/`diff`/`restore`) и
три файловые операции PowerShell и вырос с 1.5–2.5 до 2.5–3.5 ч. Аудит
глазами студента 2026-09-03 (решение 55): 8–10 → 9–11, `step-01.md`
получил установку Python и Git («Шаг 0» раздела 1.3) и вырос с 2.5–3 до
3.5–4 ч. До этого установки двух инструментов, которые нужны раньше
всех остальных, в программе не было нигде, а `step-01.md` при этом
ссылался на неё как на уже пройденную.

**Оценка сведена к вилке, не измерена** (решение 24
`design/decisions.md`). Совпадение по обеим границам — не подтверждение
оценок, а признак того, что сумма подводилась под заранее известное
число: три независимые оценки трёх шагов не попадают в заданный интервал
обеими границами случайно. `check_module_hours()` в
`tools/check_consistency.py` печатает на этот случай `[WARN]`.

Часы не переоцениваются задним числом: вторая догадка поверх первой
знания не добавляет, а сбивает единственную точку отсчёта. Разрешит
вопрос `research/self.md` — фактический лог прохождения, на 2026-07-31
пустой.

## Датасет модуля

**Категория:** сквозной модуль вне проектной привязки — синтетика по
умолчанию (третья категория раздела 1.3 curriculum-design). M0 не ведёт
напрямую ни к одному из P1–P6.

**Файлы:** `program/M0/data/` — полное описание в `data/README.md`.
Сводка:

| Файл | Роль |
|---|---|
| `generate_orders_log.py` | Генератор `orders_log.csv`, детерминирован (`SEED=20260801`, `REFERENCE_DATE=2026-08-01`) |
| `orders_log.csv` | 500 строк, эталон для критериев готовности `step-02.md` |
| `check_env.py` | Печатает версию Python и рабочую папку — первый запускаемый скрипт (`step-01.md`) |
| `view_head.py` | Первые N строк файла, замена `head` (`step-02.md`) |
| `count_lines.py` | Счёт строк, с опциональным фильтром `--status`, замена `wc -l` (`step-02.md`) |
| `find_row.py` | Поиск подстроки по всем колонкам, замена `grep` (`step-02.md`) |
| `check_utf8.py` | Проверка текстового файла учащегося на валидность UTF-8 (`step-01.md`) |
| `check_console.py` | Проверка, что терминал корректно отображает кириллицу (`step-01.md`, решение 17) |
| `reference_answers.md` | Предвычисленные контрольные числа |

Датасет намеренно "чистый" — без разных форматов дат, без дублей
написания категорий. Работа с дефектами данных — предмет M2 и M6, не M0:
здесь единственная цель — научиться пользоваться терминалом и скриптами.

Датасет не меняется между `step-01.md`, `step-02.md`, `step-03.md`.

## Зависимости модуля

Часть 3.1/3.2 blueprint: M0 — первый модуль программы, зависимостей от
других модулей нет. M0 → M1 — жёсткая зависимость (M1.1 использует
`peek_clients.py`/терминал, M1.2 использует `git commit` из `step-03.md`
этого модуля). M0 → любой шаг с кодом или Git — та же логика.
