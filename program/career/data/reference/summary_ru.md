# Резюме анализа: три источника, один объект (P4)

Задача: свести контракты Prozorro с реестром юридических лиц ЄДР по полю
`identifier.id` и назвать десятку поставщиков, получивших больше всех.

База — контрагенты 500 контрактов, 361 уникальный код. В реестре нашлось
245, не нашлось 116. Главная причина потери структурная, а не дефект
данных: 111 из 116 кодов десятизначные, это РНОКПП физических лиц и ФОП,
которых в реестре юрлиц нет по составу реестра. Необъяснённых потерь 0.

Ответ зависит от того, что делать с этими 116. Итог по всем поставщикам
без фильтра — 100 889 609.46 грн. Если исключить неподтверждённых, итог
падает до 86 108 542.77 грн, на 14.7%. Состав первой десятки меняется в
обеих версиях: из неё выпадает ФОП с десятизначным кодом, его место
занимает молочный завод с суммой 1 526 998.77 грн.

Рекомендация: публиковать оба итога рядом и называть правило отбора.
Разница в 14.7% — следствие выбора, и выбор делает заказчик отчёта.
