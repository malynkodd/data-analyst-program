# Данные модуля M16 (Looker Studio)

## Статус этого файла

Полная декларация — `program/M16/step-00.md`. У модуля нет собственного
датасета: источник — таблица `transactions`, созданная `program/M7/
step-01.md` внутри BigQuery. Эталон C4 — не число в репозитории, а
самосогласованность SQL-запроса и отчёта (датасет M7 использует
`RAND()` без seed, решение 29).

**Модуль написан без доступа к Looker Studio** (структурное ограничение,
`step-00.md`, «Отступление от конвенции модуля») — пути в меню проверены
официальной документацией Google (fetch 2026-08-21), не прогоном. Первый
реальный прогон — `DEFERRED.md`, раздел «Проверка Looker Studio».
