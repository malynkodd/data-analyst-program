# Реестр надписей интерфейса Power BI Desktop

Зачем нужен. Гейт инструментов дал шесть дефектов одного класса — R2,
R9, R10, R16, R18, R28, R31: шаг называет **результат** действия вместо
места на ленте, либо называет место **по смыслу**, а не по надписи.
Три промаха по вкладкам в двух соседних шагах (R18, R28, R31) — это уже
не описки, а привычка текста. Чинится она не правкой трёх строк, а
одним местом, где надписи записаны, и проверкой, которая не пускает в
шаги надписи, измеренные как неверные.

На чём меряно: Power BI Desktop **2.156.951.0**, установка из Microsoft
Store, русский интерфейс, Windows 11. Прогоны 2026-08-13 и 2026-08-14,
протокол — `research/tools-gate.md`, части 2 и 3.

Как пополняется. Строка появляется здесь только после того, как надпись
**увидена на экране** и записана в `tools-gate.md` с номером дефекта или
номером измерения. Надпись, взятая из документации или из памяти,
попадает в раздел 3 — с прямой пометкой, что прогоном она не
подтверждена. Правило записи пути в учебном тексте живёт в
`.claude/skills/curriculum-design/SKILL.md`, раздел 3.

Отдельно измерено и записано здесь, потому что на этом строится сразу
несколько шагов:

- вкладки **«Моделирование»** нет ни в виде «Модель», ни в виде
  «Данные» — она есть только в виде **«Отчёт»** (R18);
- в панели **«Данные»** нет поля «Количество строк» и никаких служебных
  полей вообще — только колонки таблиц (R9);
- в диалоге связей поле называется **«Кратность»** и
  **«Количество элементов»**; строки «Кардинальность» в интерфейсе нет
  (R16). Слово «кардинальность» в учебном тексте допустимо как **термин**
  — но там, где текст велит смотреть в диалог, надпись обязана быть
  дословной.

## 2. Запрещённые формы

Таблицу читает `tools/check_consistency.py`, функция `check_ui_labels`:
левая колонка ищется в каждом `program/**/*.md` по тексту со свёрнутыми
пробелами (перенос строки посреди надписи её не прячет). Найдено —
`[FAIL]`.

| Запрещено | Чем заменить | Дефект |
|---|---|---|
| `Моделирование → Управление связями` | `Данные → Средства работы с таблицами → Связи → Управление связями` | R18 |
| `Пометить как таблицу дат` | `Отметить как таблицу дат` | R28 |
| `Таблица → Отметить как таблицу дат` | `Данные → Средства работы с таблицами → Календари → Отметить как таблицу дат` | R28 |
| `Инструменты для мер` | `Средства работы с мерами` | R31 |
| `Сделать эту связь активной` | `Активировать связь` | R16 |
| `Количество строк` | нет такого поля в панели «Данные»: число строк читается в строке состояния вида «Данные» | R9 |
| `Управление связями → Создать` | `Управление связями → Новая связь` | R19 |

## 3. Надписи, прогоном не подтверждённые

экрана. Взяты из документации и из хода прогона по смыслу. Первый
реальный прогон M4 обязан их подтвердить или опровергнуть; до тех пор
