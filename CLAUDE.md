# Проект: Data Analyst Program

## Цель программы
Довести человека без опыта до первой оплачиваемой работы, где
анализ данных — основная или существенная часть обязанностей,
на украинском рынке (продукт, аутсорс, консалтинг, локальный бизнес).
Отдельным блоком — подготовка к международному найму (remote/B2B/
релокация) как к цели второго горизонта, через несколько лет работы,
а не как к результату выпуска.

Обучение: 480–644 ч (ядро 253–360, обвязка 109–136, портфолио 108–136).
При 25 ч/нед — 5–6 месяцев. При 10 ч/нед — 11–15 месяцев.
Срок поиска работы сверх этого: данных нет, не обещаем.

Русский язык. Markdown-репозиторий.

## Кто читатель
Взрослый человек без опыта в данных, учится сам, без ментора,
10–25 часов в неделю. Не студент. Ему нужна работа, а не диплом.

## Незыблемые правила
1. Всё пишется в файлы. В чат — только отчёты до 10 строк.
2. Каждое утверждение о рынке — со ссылкой на источник.
   Нет источника — нет утверждения.
3. Каждая ссылка на ресурс проверена через fetch. Битые — удалять.
4. Ни одного модуля без обоснования данными из research/market.md.
5. Ни одного шага без практики и проверяемого критерия готовности.
6. Оценки времени честные. 40 часов — значит пиши 40.
7. Тон: без воды, без мотивационных вставок, без
   "давайте вместе погрузимся в увлекательный мир данных".

## Порядок фаз
0 исследование → 1 проектирование → 2 контент → 3 карьера → 4 аудит
Не перескакивать. После каждой фазы — стоп и отчёт.
